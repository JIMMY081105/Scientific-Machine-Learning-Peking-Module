# 1.3 Plotting Functions in Julia

**Problem.** Learn to plot the standard test functions that later optimisation algorithms run on, so you can see minima and maxima before computing them.

Split by dimensionality:

| File | Goal / strategy |
| --- | --- |
| `01_Plot1DFunctions.jl` | Line plots of a quadratic and (x^3 - x)^2 with minima/maxima marked. |
| `02_Plot2DContours.jl` | Filled contour plots of the Himmelblau and Rosenbrock functions. |
