# 1.2 Julia Programming Basics

**Problem.** Learn the minimum Julia needed to read every program in this course: types, tuples/structs, arrays, operators, functions, scope, and loops.

Split by topic so you can jump to whichever you need:

| File | Topic |
| --- | --- |
| `01_Types.jl` | typeof; Int64 / Float64 / Float32 / String. |
| `02_TuplesAndStructs.jl` | Tuples, immutable structs, mutable structs. |
| `03_VectorsMatricesArrays.jl` | Column vectors, matrices, slicing, transpose, ranges, comprehensions. |
| `04_Operators.jl` | Scalar arithmetic, / vs \, matrix*vector, elementwise (.), solving A x = C. |
| `05_Functions.jl` | One-line and full functions, broadcasting, anonymous (x, p) -> ... functions. |
| `06_ScopeAndLoops.jl` | Local scope in functions/loops and for loops. |
